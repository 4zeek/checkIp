## Программа чтобы узнать ваш ip адрес

# Как ей пользоваться?
- Прописать pip install -r requests или pip3 install -r requests в папке с проектом
- Просто запустить программу и все

# Не устанавливается библиотека!
Если вы сидите на более новых дистрибутивов(ubuntu,dibian и т.д.),то вам нужно создать виртуальное окружение 
- 1 - python3 -m .venv venv
- 2 - source .venv/bin/activate
